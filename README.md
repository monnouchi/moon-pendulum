# 月の振り子 · Moon Pendulum

夜を、ひと振り。月を引いて放すと、鐘の響きが星と水面に光を広げる。
4band の Godot 4.7.2 通常版 + GDScript 製インタラクティブ音楽作品。

## 奏でる

https://monnouchi.github.io/moon-pendulum/

ソース: [monnouchi/moon-pendulum](https://github.com/monnouchi/moon-pendulum)
旧 `demo8` の公開URLは自動転送されないため、ブックマークは上記URLへ更新する。

タイトルのゆっくり揺れる月に触れると、自由に奏でる庭へ。Enter / Spaceでも同じ入口を使える。動きを減らす設定では月を静止する。
夜の開始・続き・再挑戦は庭から選ぶ。途中記録や完成曲は、タイトルから庭に入るだけでは消えない。タイトル右上の音の印とMで音の設定を選べる。
月を左右へ引いて放す。強さによって鳴る鐘と光の広がりが変わる。
左上で重力（弱 / 標準 / 強）、右下で「蒼の夜 / 灯りの夜 / 白む夜」の色と音色を変えられる。

- 三つのオリジナル音色。左右の鐘と小さな副振り子が、立体的な響きをつなぐ
- 庭は D メジャーの五音 D / E / F♯ / A / B。旅では主月の鐘から夜ごとに構成音が変わる
- 引いている間の柔らかな音、離した後の響き、伸びる光の軌跡、水面の反射
- 星を灯すたび高いフレーズが重なり、星座が完成すると滑らかな低音とともに曲が続く。次の夜へは余韻と静寂を置いて移る
- 日本語明朝、マウス / タッチ / キーボード、ミュートと一時停止
- 音は最初の操作後に有効。タブ・アプリを離れると音を止める

キーボード: ← → 長押しで調整、Space で放す、R で引き直し、M でミュート、P で一時停止、H で説明、庭では N で夜の色と音色。

「星を灯す遊び」は任意の短い旅。金の輪で月を折り返すと、上の星座が灯る。
放す位置の正解は示さず、未点灯の輪と前の折り返しを見比べて試せる。どの輪から灯してもよい。主月と小月の最初の二回の折り返しで、一振りから複数の光を狙える。
未達の直後は折り返しの印と差分の弧を短く強調し、連続して届かなかった時だけ小さな助言を添える。成功や再開で消え、音名や動く月の上には重ねない。
最初の夜から、主振り子 → 鐘 → 小さな月の連鎖を体験できる。
放し直すと、小月の前の位置から中央へ短い光が戻る。外側の鐘で力がたまり、中央の鐘から小月へ渡る瞬間も細い光で結ぶ。物理や達成条件は同じで、動きを減らす設定では光を移動させず線を短く灯す。
5つの夜、11の届け先・15の光。オリオン座、こと座、カシオペヤ座、はくちょう座、さそり座の主要星を描き、最初から見える24の淡い星へ15の欠けた星を足す。固定した観測条件の星表配置を一様に縮尺した39星で、星座の姿と「○○座の夜」という名前を結ぶ。対の課題は、離れた二つの星と元の二つの音楽層に対応する。
Iは「三振りで、この星座を」、II〜Vは「二振りで、この星座を」。放した振りを数え、目標を超えても完成まで奏でられる。Iの主月と小月、IIの外側と内側の対、IIIの戻る主月と小月、IVの左右の連鎖、Vの精密な外側と内側の対へ進む。
引き直しても手数と灯りは保つ。説明の「この夜を結び直す」で星座と手数を初めから試せる。完成時は手数を静かに添え、最少記録は端末内で保持する。遅い再演で良い記録を上書きしない。途中でも庭へ寄り道し、続きへ戻れる。
夜の下部は夜名・点灯・手数の一行と小さな操作にまとめ、星座に広い空を使う。目標手数と詳しい説明はHで開き、短い反応は必要な間だけ表示する。下部操作の見た目を小さくしても、元のタッチ領域と左右へ引く範囲を保つ。導入の大きな星座が空へ引く順序と時間は同じ。
夜ごとに異なる拍子・旋律・音色のオリジナル曲。II/Vは小さな月が一つ届くと短く応え、二つがそろった時だけ続くフレーズが増える。
I は Dadd9 の五音、II は C と F♯ を持つ A ドリアン、III は G と F♯ が滲む Em9、IV は C・F・A の G9sus4、V は C♯ と E が重なる Dmaj9。V は最初の D に帰り、違う色の余韻を残す。
順番を変えて灯した星も、それぞれの元の音楽層に対応する。主月・引く途中の音・小月・星の層・完成低音は一つの音高表を共有する。静かな主音と五度から始まり、星が増えるにつれ第三音や7th・9thが重なる。
完成した曲は好きなだけ聴ける。次の夜を選ぶと、音と画面が1.8秒かけて消える。暗転中に0.4秒の静寂を置き、新しい夜の静かな音と空が0.8秒で現れる。
完成文は3.5秒そのまま表示し、1.5秒かけて穏やかに消える。動きを減らす設定では、読む時間を保って消去を0.5秒に短縮する。
初めての夜では、不完全な星座が先に見え、0.8秒後から既存の明朝で夜の名が浮かぶ。3.6秒の鑑賞から4秒のゆっくりした下降へ移り、星座は空へ引き、振り子と水面が下から現れる。カメラは描画だけに作用し、下降が終わるまで演奏入力を受け付けない。動きを減らす設定では空を静止し、下降を0.5秒の暗転による溶け込みに替える。
同じ夜の途中再開・再試行・完成曲の再開では導入を繰り返さない。新しい一周ではまた空から始める。中断と説明は導入・遷移も止め、戻ると残りの余韻と景色から再開する。ミュートや非表示時の消音はすぐ応答する。
クリアと途中の状態、完成した曲を聴いていた夜は端末内に保存。再開しても完成時の演出は繰り返さない。最初から遊ぶ操作は説明画面に分けている。
最終Vの完成曲は再読込後も、庭の「音のつづき」から聴ける。完成Vから明示的に庭へ戻ると一周を終了し、「もう一度」でIの未達状態から再演する。ベスト記録と設定は保つ。
Webの小さな記録は localStorage と Godot の user:// に保存し、外部へ送信しない。version 1に点灯の配列と最少手数、導入を見た印を追加し、旧記録は従来の進行と設定を引き継ぐ。旧評価から手数の記録は作らない。
改名後も同じブラウザの記録を引き継ぐため、保存キー `moon-pendulum.demo8.save.v1` と Godot のアプリ名・保存先を維持する。

リポジトリの Pages 設定はワークフローで変更しない。
設定前もビルド・テスト・ダウンロード用 `moon-pendulum-web` を生成する。

## ローカル制作

Godot **4.7.2 standard** と同バージョンの Export Templates、Python 3。

```sh
python tools/build_assets.py
godot --headless --path game --editor --import --quit
godot --path game
```

Web:

```sh
mkdir -p docs
godot --headless --path game --export-release Web ../docs/index.html
python -m http.server 8000 --directory docs
```

http://localhost:8000 を開く。ファイルの直接起動には対応していない。
Compatibility / single-thread Web export、WebGL 2.0 + WebAssembly。
COOP・COEP ヘッダー不要。Web Audio Sample 再生、残響と立体感は音源に焼き込んでいる。
音量が変わらない時は再送せず、停止済みの声の更新は省く。各声の余韻・遷移・中断からの復帰は保つ。
鐘とフレーズは既存の録音の再生速度で音高を選ぶ。起動時に倍率を計算し、演奏中の音源生成・声のプール・楽譜の発音数は増やさない。完成低音は主音を焼き込んだ4種を事前生成し、I/Vは共用する。Web Sampleのループ再開でも主音を保つ。
初回は公式 Godot エンジン約38MBを含む。
待機画面の月と細い光は実際の読み込み進捗に連動する。日本語と小さな英文タイトルを添え、タイトルの初回描画後に短く溶けるように移る。フェード開始から操作できる。動きを減らす設定に対応し、読み込みが止まった場合は再試行を表示する。

## 構成とライセンス

`game/` がソース。`tools/build_assets.py` と `tools/build_music.py` がオリジナルのステレオ音源と同梱フォントを再構築。`game/scripts/night_harmony.gd` が5夜の構成音と楽譜、`game/scripts/night_music.gd` が音楽の進行を管理する。
`docs/` は生成される Web export。Git に含めず Actions artifact として配布。
公開成果物に本作・フォント・Godot/依存ライブラリのライセンスを同梱。

星空と季節の基準: [観測条件・出典と計算の説明](SKY_SCENES.md)。北緯35°・東経135°・高度100mの固定地点で5夜を計算し、星表に基づく周辺星・実際の月・冬の静かな雪・夏の水面を描く。

星座の名前と簡略接続線: [IAU / Sky & Telescope星図](https://iauarchive.eso.org/public/themes/constellations/) の ORI / LYR / CAS / CYG / SCO と照合した簡略描画。恒星位置はBSC5とIAU SOFAによる観測方向へ更新し、観測用の星図としての精度や地上の厳密再現は意図しない。[国立天文台の説明](https://www.nao.ac.jp/news/blog/2022/20220809-constellation.html) にあるとおり、星座の範囲と星を結ぶ線は別に扱う。星図画像を参照し、ゲームには計算済みの位置と独自の簡略線を使う。
